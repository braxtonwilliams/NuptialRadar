# Nuptial Radar — Documentation

This folder contains detailed documentation for the **Nuptial Radar** project: a browser-based ant nuptial flight predictor built as a web recreation of [nuptialflight](https://github.com/bradrushworth/nuptialflight).

## Documents

| Document | Description |
|----------|-------------|
| [**Project Guide**](./project-guide.md) | Complete reference: architecture, features, algorithms, database, weather APIs, UI, and development |

## Quick links

- **Run locally:** `npm install && npm run dev` → http://localhost:5173
- **Repository:** https://github.com/braxtonwilliams/NuptialRadar
- **Upstream models:** https://github.com/bradrushworth/nuptialflight (GPL-3.0)
- **Weather data:** https://open-meteo.com/
